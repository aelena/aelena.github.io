Selected work · Applied AI

AI with tests, evaluations and provenance

Public repositories, each with CI, tests and a README that says what was measured. Everything below runs locally first and treats a model's output as a claim to verify, not a fact.

RAG Advisor

Python · PyPI ragadvisor · CLI, library, Claude Code skill

Analyses a document corpus and the infrastructure constraints, then recommends a complete RAG configuration: embeddings, chunking, hybrid retrieval, vector store, reranker, sizing, cost and latency. Every number carries its provenance, and --validate measures the recommendation against ground-truth queries before anything is indexed.

10 releases~300 tests, CI on 4 Python versionsresponds to an external review in its changelog

Agentic Board (Idea Refiner)

Python · CrewAI · Sanic API · Svelte UI · MCP

A boardroom of AI agents declared in YAML: hostile round, chair-led deliberation, coaching and synthesis, with a refine loop that sends the revised idea back to the board. Seats can be grounded in a local library or a company's records through MCP, and every verdict carries confidence, caveats and open questions.

blind eval, 20 ideas: board 13, single model 0, split 784 testslocal models supported

Trustworthy AI Body of Knowledge

24 pages · 5 code modules · tai-lab · since 2024

A programme for an in-house AI assurance capability: bias, explainability, adversarial robustness, evaluation frameworks, differential privacy, the EU AI Act timeline, agentic safety. Prose under CC BY, code under MIT, and a companion lab that runs the evaluations against a model you choose.

quarterly reviewedAI Act, NIST AI RMF, OWASP LLM

Documentation Curator

Python · CLI, REST API, browser UI

The step every knowledge-base project skips: point it at a folder and it reports what the documents are worth as text. Per-file metrics, OCR quality, PII with checksum validation, Markdown-convertibility verdicts, duplicates and versions, topic clusters, and a curation plan with one recommended action per file.

334 tests30+ formats incl. CAD and geospatial

c-tiktoken

C23 · BPE tokenizer · tutorial and book

A complete implementation of OpenAI's tokenizer in C, written as teaching material. Differential tests against the Python package (3,000 comparisons per push) and fuzzing of both parsers found real bugs, and the README says which. The eight-chapter tutorial became the book below.

sanitizer and fuzz CI54 commits, 12 PRs

FlowTrack

FastAPI · SvelteKit · PostgreSQL · MCP server · Chrome clipper

An opinionated portfolio tracker that makes you write down when to quit: abandonment criteria and pre-mortems up front, subjective completion against the figure computed from tasks. Driven by an agent through its MCP server rather than by a chat window, with a Claude Code skill that keeps each repo's record honest.

Selected work · Software engineering

Libraries and tools that ship with tests, CI and a licence story

Aelena.FileApi

.NET 10 · HTTP API, CLI, gRPC, NuGet

One pure core library exposed four ways: about 130 HTTP routes, a CLI, gRPC and three NuGet packages. PDF, DOCX, XLSX, PPTX, CSV, EPUB, MOBI, email and more, with PII detection and hashing. The AGPL PDF engine is isolated in its own package so the core stays MIT, and the pipeline produces an SBOM, runs CodeQL and dependency review.

1,060 teststrusted publishing to NuGetJWT hardening, rate limiting, RFC 9457 errors

PerceptualHash.NET

.NET · NuGet · aHash, dHash, pHash

Perceptual image hashing bit-compatible with the Python imagehash library, verified against a golden dataset. A pixel budget against decompression bombs, first-frame-only decoding and strict parsing, with a written threat model. Small on purpose, and finished.

100% line coverage480 tests

Common-Extensions 2.x

C# 14 · netstandard2.0 to net11 · NuGet since 2014

A 2014 library rewritten from scratch in 2026 under its original NuGet id, keeping only what the base class library still lacks: string metrics (Levenshtein, Damerau, Jaro-Winkler), sequence operators and functional helpers. Every README example is asserted by a test.

457 tests × 4 targets, 100% coverage7,000+ downloads

Dorksmith

TypeScript + Python · npm, PyPI, GitHub Pages

A deterministic generator of search-operator queries for OSINT and defensive exposure discovery. Two engines, one in JavaScript and one in Python, kept identical by 153 shared golden fixtures. No model involved, by design: when the output must be exact, a rule beats a guess.

Background and method

A polymathic path, deliberately

A degree in English philology and six years as a technical translator came before the first line of production code in 2001. Since then: developer, architect, head of a global architecture function, CTO, with detours through a master's in data engineering, an INSEAD programme on business strategy and a digital MBA for technology leaders. On the side, philosophy, music, photography and languages. The pattern is not breadth for its own sake. It is what the industry now calls an M-shaped profile: deep in architecture and AI, and able to move between product, strategy and organisational design without losing the thread.

Most technology decisions get answered before anyone has agreed what the question is. That is how a defensible architecture becomes an expensive one.
