RAG Advisor

Python · PyPI ragadvisor · CLI, library, Claude Code skill

Analysiert einen Dokumentenkorpus und die Infrastrukturvorgaben und empfiehlt eine vollständige RAG-Konfiguration: Embeddings, Chunking, hybride Suche, Vektorspeicher, Reranker, Dimensionierung, Kosten und Latenz. Jede Zahl trägt ihre Herkunft, und --validate misst die Empfehlung an Referenzanfragen, bevor irgendetwas indexiert wird.

Agentic Board (Idea Refiner)

Python · CrewAI · Sanic API · Svelte UI · MCP

Ein Gremium aus KI-Agenten, in YAML deklariert: feindliche Runde, vom Vorsitz geführte Deliberation, Coaching und Synthese, mit einer Verfeinerungsschleife, die die überarbeitete Idee zurück ins Gremium gibt. Sitze lassen sich über MCP in einer lokalen Bibliothek oder in Unternehmensunterlagen verankern; jedes Urteil trägt Konfidenz, Vorbehalte und offene Fragen.

Hintergrund und Methode

Ein polymathischer Weg, mit Absicht

Ein Abschluss in Anglistik und sechs Jahre als technischer Übersetzer gingen der ersten Zeile Produktionscode im Jahr 2001 voraus. Seitdem: Entwickler, Architekt, Leiter einer globalen Architekturfunktion, CTO, mit Umwegen über einen Master in Data Engineering, ein INSEAD-Programm zu Unternehmensstrategie und einen Digital MBA für Technologieführungskräfte. Daneben Philosophie, Musik, Fotografie und Sprachen. Das Muster ist keine Breite um ihrer selbst willen. Es ist, was die Branche heute ein M-förmiges Profil nennt: tief in Architektur und KI, und fähig, sich zwischen Produkt, Strategie und Organisationsdesign zu bewegen, ohne den Faden zu verlieren.

Die meisten Technologieentscheidungen werden beantwortet, bevor jemand sich darauf geeinigt hat, was die Frage ist. So wird aus einer vertretbaren Architektur eine teure.
